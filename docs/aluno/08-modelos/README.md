# 08 — Modelos de entrega

Modelos editáveis para as entregas das SAs. Copie o arquivo para a pasta da sua equipe antes de preencher
(ex.: `entregas/grupo-2/`), mantendo o nome do modelo no início do arquivo.

| Modelo | Arquivo | SA |
| --- | --- | --- |
| Matriz de rastreabilidade (abre no Excel/LibreOffice/Planilhas, separador `;`) | [matriz-rastreabilidade.csv](matriz-rastreabilidade.csv) | 1 |
| Plano, caso de teste, execução e relatório | [caso-de-teste.md](caso-de-teste.md) | 1 |
| Registro de falha | [registro-de-falha.md](registro-de-falha.md) | 1 e 3 |
| Checklist de implantação e termo de validação | [checklist-implantacao.md](checklist-implantacao.md) | 2 |
| Registro de mudança | [registro-de-mudanca.md](registro-de-mudanca.md) | 3 |
| Registro de atendimento | [registro-de-atendimento.md](registro-de-atendimento.md) | 3 |

Os arquivos `.md` podem ser editados no VS Code (visualização: `Ctrl + Shift + V`) ou copiados para um
editor de texto. Identifique sempre os requisitos pelos IDs da [especificação](../00-especificacao-de-requisitos.md).
